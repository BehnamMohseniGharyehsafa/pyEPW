# pyEPW 0.4.1

Actual-calendar-year EPW, CSV and TXT exports with `import pyEPW`.

- Source-specific attribution and licence scopes travel with every new export.
- Six real 2024 examples cover Europe, Africa, Asia, North America, South America
  and Oceania; compact source-attributed chart inputs are in the repository.
- Architecture, class UML and sequence diagrams explain the implementation.
- Offline unit tests, cross-platform CI, installed-wheel checks and reproducible
  figures support maintenance. Legacy imports and CLI aliases remain available.

The code is MIT-licensed. Downloaded data and hosted API access retain separate
conditions: see DATA_SOURCES.md. Open-Meteo's hosted free API is non-commercial
and rate-limited. No PyPI upload or paid service is initiated by this release.

Weather is reanalysis/derived, not exact city-site measurements. Source gaps and
unsupported fields remain explicit. The historical twenty-year benchmark is a
version 0.2.0 snapshot, not global certification of all 0.4.1 fields.
